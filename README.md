## Featured Projects

### [AI Research Agent](https://github.com/dhruvb2028/AI-Research-Agent)

An agentic research assistant that plans web and document searches, gathers evidence, and produces answers with traceable citations. Its evaluation harness records correctness, citation faithfulness, latency, estimated cost, and execution traces.

`Python` `FastAPI` `React` `Agent Evaluation` `Retrieval`

### [Forge — AI App Builder](https://github.com/dhruvb2028/AI-App-Builder)

A full-stack application generator with bounded planning, generation, editing, and repair workflows. It uses structured model outputs, file validation, streamed progress, version history, and sandboxed live previews.

`Next.js` `TypeScript` `Supabase` `Sandpack` `LLM Agents`

### [AI Voice Receptionist](https://github.com/dhruvb2028/Al-Voice-Receptionist-Platform)

A multi-tenant voice receptionist for home-service businesses. The system covers realtime conversation, calendar booking, emergency escalation, tenant isolation, and deterministic guardrails against unsafe model behavior.

`Python` `FastAPI` `PostgreSQL` `Realtime Voice` `Guardrails`

### [Drift Audio](https://github.com/dhruvb2028/Drift-Audio)

A deployed full-stack audio storefront with authentication, persistent shopping state, Stripe Checkout, verified webhooks, and user-scoped order history.

`Next.js` `TypeScript` `Stripe` `Clerk` `Prisma` `PostgreSQL`

[Live Demo](https://drift-audio.vercel.app) · [Source Code](https://github.com/dhruvb2028/Drift-Audio)

## Engineering Focus

- **Agent reliability:** bounded workflows, schema validation, retry limits, and explicit stop conditions.
- **Evaluation:** labelled test sets, regression reports, execution traces, latency measurement, and failure analysis.
- **Product engineering:** responsive interfaces, API design, authentication, persistence, payments, and deployment.
- **Safety and integrity:** deterministic guardrails, verified webhooks, server-owned trust boundaries, and tenant isolation.
